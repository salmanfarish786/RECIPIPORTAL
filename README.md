AI Recipe Portal

The AI Recipe Portal is an intelligent cooking assistant designed to help users find recipes based on the ingredients they already have. By leveraging AI-driven recommendations, the system suggests personalized recipes, provides detailed preparation steps, cooking time, nutritional information, and ingredient substitutions when needed.

Features
AI-based recipe recommendations
Ingredient-based recipe search
Step-by-step cooking instructions
Personalized recipe suggestions
Nutritional information display
User-friendly interface
Reduces food waste by utilizing available ingredients
Technologies Used
Frontend: HTML, CSS, JavaScript
Backend: Node.js
Database: MySQL
AI Recommendation Engine
