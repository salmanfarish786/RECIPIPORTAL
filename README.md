# 🍽️ Cooking Robot - Recipe Portal

A stunning, modern recipe discovery platform with smooth animations, beautiful food imagery, and intelligent ingredient matching.

## ✨ Features

- **📸 Real Recipe Images** - Beautiful food photography for each dish
- **🎨 Figma-Style Animations** - Smooth transitions and interactive effects
- **🔍 Smart Search** - Filter by cuisine, search by ingredients
- **🥘 Pantry Matcher** - AI-powered recipe suggestions based on your ingredients
- **📱 Fully Responsive** - Works beautifully on desktop, tablet, and mobile
- **🎯 YouTube Integration** - Direct links to step-by-step cooking videos
- **⚡ Fast & Lightweight** - No heavy frameworks, pure vanilla JavaScript


## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Advanced animations and gradients
- **Vanilla JavaScript** - No dependencies
- **TheMealDB API** - Recipe and ingredient images

## 📖 How to Use

### Explore Recipes
- Browse all recipes in the grid
- Search by recipe name or cuisine
- Filter by cooking time and craving type
- Sort alphabetically or by quickest

### Find Recipes by Pantry
- Enter your available ingredients
- Set your time preference
- Get AI-ranked recipe suggestions
- See what ingredients you're missing

### Get Cooking
- Click "Open Recipe" to view full details
- Watch step-by-step tutorials on YouTube
- Access ingredient lists and cooking instructions

## 🎨 Design Highlights

- Warm, inviting color palette inspired by global cuisines
- Smooth Cubic-Bezier animations (0.3-0.6s)
- Card hover effects with depth elevation
- Floating ingredient animations
- Staggered grid animations for visual flow
- Custom animated scrollbar
